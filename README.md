# ⚽ Premier League Dashboard

Dashboard interativo com análises históricas da Premier League (2000–2025).

## Tecnologias

- Python, Pandas, Plotly, Dash

## Como rodar

1. Instale as dependências: `pip install -r requirements.txt`
2. Execute o dashboard: `python dashboard/app.py`
3. Acesse: http://127.0.0.1:8050

## Análises

- Média de gols por temporada
- Campeões históricos
- Times mais rebaixados
- Impacto da torcida nas vitórias em casa
- Top artilheiros e jogadores mais decisivos (2024/25)
